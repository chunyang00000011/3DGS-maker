3. 五阶段算法与参数精调

01抽帧预处理 ingest
抽帧率 (fps) 推荐 1.5–3
控制采样密度；总帧数控制在 80–160 帧时 COLMAP 速度与精度最均衡。
02相机位姿解算 pose

COLMAP 默认使用 SIMPLE_RADIAL（单焦距 + 自动去畸变）防止畸变偏移；广角相机可选 OPENCV_FISHEYE。

03SOTA 3DGS 重建 reconstruct

3DGS-MCMC 将废球重定位到高频细节区域，在有限显存内画质最稳。

训练步数 iterations 推荐 20k–30k
最大高斯点数 max_points 室内推荐 50万–80万
实景画面精细度核心参数：复杂桌面建议 50万点，室内大场景建议 80万–100万点。
球谐阶数 sh_degree SOTA 默认 3 阶
高级几何正则与外部论文参数

扁平正则压薄高斯球贴合物体表面；纯视觉可调至 0.002，抓取仿真建议 0.01。

04后处理与碰撞网格 postprocess
体素精度 48–72
尺度微调无需重训 3DGS，改好 scale_factor 后选「04 postprocess」断点重跑即可秒出新模型。
05成果格式导出 export
物理凸包块数 6–16
